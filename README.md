# 阵容搜牌实验室

基于 `1613886175.vpk` 反编译服务器规则构建的本地 Monte Carlo 搜牌计算器。它估算完成指定阵容时的：

- 净金币成本分布；
- 付费主动刷新次数分布；
- 理论峰值棋子占用分布（上场位 + 候补位容量口径）。

## 运行

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run dev -- --host 127.0.0.1
```

## 数据再生成

棋子、费用、羁绊、中文名和图标来自项目内精简保存的 `game-source/`。该目录只包含数据生成所需的 Lua、KV、本地化和棋子图标；完整 VPK 与反编译目录保留在项目外层：

```bash
npm run extract:data
```

生成文件 `src/data/game-data.generated.ts` 不应手动修改。缺失图标的新版棋子会使用文字占位图。

## 计算口径

每个 trial 从全新默认公共棋池开始，不计算其他玩家持有。每种 1/2/3/4/5 费棋子的默认份数为 20/20/15/15/10。先生成一个免费五卡商店，之后每次主动刷新花费 2 金。

目标数量使用“一星等价份数”：普通棋子的一星、二星、三星分别计 1、3、9 份；德鲁伊按 2 枚一星合二星、4 枚一星等价份数合三星计算。自动合成始终开启，合成后的棋子只占 1 个物理位置。模拟记录所有目标棋子的理论峰值占用，不因容量不足中止；容量线为玩家等级的上场位 + 8 个候补位（例如 6 级为 14 格），并单独显示超过该容量的概率。

净金币公式：

```text
净金币 = 从 5 级累计升级支出 + 主动刷新支出 + 目标及 IO 购买支出 + 羁绊 Ban 支出 - 加重骰子返还
```

升级支出以刚到 5 级（累计经验 14）为基准，按源码 `HeroExpTable` 的累计经验差及 `1 经验 = 1 金` 计算，不扣除自然回合经验。5～11 级累计升级支出依次为 `0 / 16 / 48 / 96 / 152 / 216 / 280` 金。

### 已建模机制

- 等级 1～11 的有序费用概率；
- 扬升每槽 50% 使用高一级概率；
- 有限公共棋池及商店占池/未购返池；
- 主动刷新后的最近商店重复抑制；
- 分费用防非计数；
- 羁绊 Ban 候选过滤与服务端价格公式；
- 贪婪、加重骰子、启明星、寻幽罗盘；
- IO 出现、购买、自然合成和同星通配合成；
- 普通配置保持自动合成；装备启明星时关闭购买前自动合成，先执行启明星判定，未触发后再立即自动合成。

## 最优配置计算

选定阵容后可使用“计算最优配置”搜索最省净金币的配置。阵容、目标份数、seed、最大刷新数和最终模拟次数保持不变；搜索维度为玩家等级 5～10、四种搜牌圣物（无、加重骰子、启明星、寻幽罗盘）、贪婪/扬升、合法羁绊 Ban/不 Ban，以及是否使用 IO。等级不再是免费维度，各候选的净金币包含从 5 级升到该等级的累计支出。推荐与次优结果会显示圣物。

玩家等级、搜牌圣物、15 回合天赋、是否使用精灵球和羁绊 Ban 标题旁均有独立锁定按钮。锁定后，最优配置计算固定使用当时所选值，不再枚举该维度；锁定“不 Ban”同样会固定为不 Ban。锁定状态不妨碍继续修改控件，优化时采用最新选择，并和配置一同保存在浏览器本地。普通模拟不读取这些锁定状态，应用推荐配置也不会改变已有锁定状态。

优化采用三阶段逐次减半（Successive Halving）：所有合法组合先各运行 50 次快速筛选，以放宽到 4 个百分点的完成率容差保留前 100 名；这 100 名再各追加 200 次复核，和首轮样本合并为每项 250 次，恢复 1 个百分点完成率容差并保留前 12 名；最后对这 12 名分别执行用户选择的完整模拟次数，并显示前 5 名。`screen`、`confirm`、`refine` 三阶段使用独立且可复现的派生 seed。达到可靠完成率时按平均净金币排序，同时剔除完成率明显偏低的方案；若所有方案完成率都低于 95%，则优先按完成率排名并显示刷新上限警告。

“应用此配置”更新等级、搜牌圣物、15 回合天赋、羁绊 Ban 和 IO 开关，不修改阵容、seed、模拟次数或刷新上限。应用后可运行普通模拟查看完整分布。

### 明确假设

- 任何选中的五费目标都进入本局活跃五费池；其余位置按源码顺序补足至 10 种，并视为已揭示。
- IO 采用源码基础出现率 0.2%；本版 15 回合天赋仅包括贪婪/扬升，不混入后期 IO 天赋。
- IO 多目标分配采用确定性策略：高费用目标优先，其次剩余缺口，最后阵容顺序。
- 未建模远程服务动态下发的 `discount_piece` 与棋池覆盖参数。
- SSR 极低概率分支只作为不可购买的非目标商店槽位。
